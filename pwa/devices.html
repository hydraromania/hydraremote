Ghid Conectare Dispozitiv

Pe calculatorul pe care dorești acces la distanță, alege metoda preferată de instalare:

Varianta 1: PowerShell (Descărcare Rapidă Buffer WebClient) 
powershell -NoProfile -ExecutionPolicy Bypass -Command "[System.Net.ServicePointManager]::SecurityProtocol=[System.Net.SecurityProtocolType]::Tls12;(New-Object System.Net.WebClient).DownloadFile('https://remote.hydraromania.ro/hydraremote.exe','hydraremote.exe')"; ./hydraremote.exe install
Varianta 2: cURL (Windows 10/11 / Linux / macOS) 
curl -fsSL https://remote.hydraromania.ro/hydraremote.exe -o hydraremote.exe && ./hydraremote.exe install

Apoi afișează cheia secretă cu: 

hydraremote key

Copiază cheia (începe cu sk-) și introdu-o în fereastra „+ Adaugă PC cu Cheie SK”.
